# Iteration 1 — Content & Knowledge

**Ship this first.** Everything in this iteration is self-contained, requires no real-world data sourcing beyond what's already publicly available, and gives you the topical authority foundation that makes Iteration 2 (geo) worth building later.

## What's in scope

| Page type | Volume target (end of Iteration 1) |
|---|---|
| Technique (canonical + variations) | 400–600 |
| Position & concept hubs | 40–60 |
| Belt pages | 5 |
| Curriculum modules | 15–25 |
| Flow / transition pages | 50–100 |
| Glossary terms | 150–250 |
| Drills | 80–150 |
| Athletes | 100–200 |
| Events + series | 40–80 |
| Reviewer / author profiles | 3–10 |
| **Total** | **~1,000–1,500** |

These volumes assume solo operation with LLM-assisted drafting and automated gates. If you can sustain higher cadence, scale up — but never at the cost of the gates in `QUALITY-GATES.md`.

## What's NOT in scope

- Gyms, cities, states → Iteration 2
- Gear/commercial pages → Phase 4 editorial work, not Iteration 1
- Blog/editorial posts → parallel track, handled outside the programmatic pipeline
- Portuguese locale → defer until English Iteration 1 is stable

## Reading order

1. **`STRATEGY.md`** — the rationale: what page types, what volumes, why this order
2. **`DATA-SCHEMAS.md`** — the record shapes you'll need to define in your CMS/DB
3. **`TEMPLATES.md`** — exactly how each record becomes a rendered page, with worked examples
4. **`QUALITY-GATES.md`** — the automated gates and your ad-hoc sampling workflow

## One-line summary

> "Build the open web's most structured BJJ knowledge base — 1,000–1,500 pages across techniques, positions, belts, flows, drills, glossary, athletes, and events — using LLM-assisted generation with strong automated gates, shipping in small batches you can sample yourself."
